# The_sNake_Challenge

# Quiz 03 - Dynamic Arrays and Amortized Analysis

## Versión de Java

Requerido: **Java 16** o superior (utiliza la característica de `record`).

## Instrucciones de Compilación y Ejecución

### Desde la línea de comandos (Terminal)

1. Navegar a la raíz del proyecto.

2. Compilar los archivos fuente:

   ```
   javac -d bin src/*.java
   
   ```

3. Ejecutar la clase principal que reproduce la traza de la Pregunta 3:

   ```
   java -cp bin src.Main
   
   ```

### En OnlineGDB

1. Seleccionar el lenguaje **Java**.

2. Copiar el contenido de cada archivo respetando su estructura de paquetes o colocar todas las clases dentro de `Main.java` marcándolas como `static` o de visibilidad de paquete.

3. Asegurarse de seleccionar una versión de JDK >= 16.
